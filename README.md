# 🏞️ 南投家鄉景觀探險隊 ── 360° 看見家鄉的自然與人文

國小社會四上（南一版）第三單元第一課〈家鄉的景觀〉的 360° 互動教材。
獨立專案，與「南投食農小旅行」系列不共用程式、存檔或圖檔。

| 站 | 景點 | 課本小節 | 徽章 |
| :-- | :-- | :-- | :-- |
| 1 | 魚池・日月潭 | 自然景觀 p.46 | 湖光山色觀察員 |
| 2 | 草屯・九九峰 | 自然景觀＋變遷（時光機） | 地形小偵探 |
| 3 | 鹿谷・溪頭 | 自然景觀 p.46 | 森林守護員 |
| 4 | 南投市・藍田書院 | 人文景觀 p.47 | 書院小學士 |
| 5 | 竹山・紫南宮 | 人文景觀 p.47 | 廟埕解說員 |
| 6 | 水里・車埕 | 人文景觀＋變遷 p.49 | 木業小站長 |
| 7 | 集集・車站與武昌宮 | 景觀的變遷 p.49（時光機） | 重建見證員 |
| 8 | 南投市・中興新村 | 景觀的變遷 p.48（時光機） | 新村規劃師 |

- 每站 7 個線索＋1 個彩蛋、4 題（答案平均分在 A～D）。
- 第 2、7、8 站有「⏳ 時光機」，可依序比較以前與現在。
- 終極任務：先把 8 站分成自然／人文景觀，再判斷 4 個變遷景點的原因（天然災害／人為）。
- 證書頁可寫上「我推薦的家鄉景觀」（接課本 p.45 動動腦），會印在證書上。
- 進度存檔鍵：`nantou_landscape_explorers_progress`。

## 怎麼開啟

- **直接雙擊 `index.html`**：可離線使用。
- **`開啟網站.bat`**：用本機伺服器開啟（http://127.0.0.1:8091），換圖後看得最即時。
- **學生獨立版**：`dist/南投家鄉景觀探險隊_學生獨立版.html`，單一檔案，可直接發給學生。
- **教師模式**：網址後面加 `?teacher`，所有站直接開放，畫面中央會出現紅色準心並顯示 x、y 百分比，用來校準線索位置。

## 換上 Codex 正式圖

1. 依「Codex 生圖規格書」把圖放到對應資料夾：
   - `pano/s1_sunmoonlake.jpg` … `pano/s8_zhongxing.jpg`，以及 `pano/hotspots_sN.json`
   - `timemachine/s2_a.jpg`、`s2_b.jpg`、`s7_a.jpg`、`s7_b.jpg`、`s8_a.jpg`、`s8_b.jpg`
   - `ui/badge_s1.png` … `ui/badge_s8.png`、`ui/hero_map.jpg`
   - `cert/certificate_bg.png`、`mascot/ahu_wave.png`
2. 雙擊 `同步素材.bat`（或執行 `python sync_assets.py`）。

同步程式會：正式圖優先、沒有才用 `_placeholder/` 的示意圖；讀 `hotspots_sN.json` 自動套用線索位置；
產生網頁用縮圖到 `build/`；重建 `data/eras.js`、離線素材與學生獨立版。
示意圖在畫面上會標「示意圖」，換上正式圖後自動消失。

## 改內容

所有文字（線索、題目、時光機說明、終極任務、比較表、證書文字）都在 `data/eras.json`。
改完後執行 `同步素材.bat`。線索位置用 x、y 百分比（從圖片左上角算起），程式會換算成 360° 角度。

## 資料夾

```text
index.html            學生端網頁
data/eras.json        全部教材內容（唯一需要手改的資料）

js/landscape.js       景觀版新功能：時光機、終極任務、我的家鄉景觀、教師準心
js/*.js、css/          沿用 360 導覽引擎（Pannellum）
pano/ timemachine/ ui/ cert/ mascot/   Codex 正式圖
_placeholder/         示意圖（tools/make_placeholders.py 產生）
build/                自動產生的網頁用圖
dist/                 學生獨立版
```
